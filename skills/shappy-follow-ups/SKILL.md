# Follow-ups

1. Call `shappy_overview`, then use the apps' read actions to find records waiting on someone outside the company, as each app's instructions describe them.
2. List them oldest first, with who it is, the amount if any, and how long it has waited. Use only dates the app returned.
3. For each one the person wants to chase, draft a short, polite message in their language.

## Rules

- Show the draft and let the person send it. Never send it from here.
- Never add a discount, a deadline or urgency the person did not ask for.
- Never change a record because of a follow-up. Record an answer only when the person tells you it came.

Give the `openInApp` link so they can open each record.
