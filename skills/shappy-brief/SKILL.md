# Daily briefing

1. Call `shappy_overview`, then use the list actions of the installed apps. Only read: a briefing changes nothing.
2. Give a short summary, most urgent first:
   - quotes waiting for a client's reply
   - drafts not finalized yet
   - anything else the apps list as needing attention
3. End with the one thing worth doing first, and the `openInApp` link.

Report only what the apps returned. If an app has no list action, say what you could not check. Keep it under ten lines.
