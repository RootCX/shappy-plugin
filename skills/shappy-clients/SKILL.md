# Clients in SHAPP

1. Always search first with the app's find action, and reuse an existing record.
2. Create a client only when the person identified a real one. Leave anything they did not give you empty.
3. To update, read the full record and send it back complete.
4. Never treat the recipient of an old document as a new client unless the person asks for that.

To answer "what's happening with this client", combine the client record with the app's quote list, filtered by their name.
