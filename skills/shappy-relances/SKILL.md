# Quote follow-ups

1. List quotes with the app's list action, then keep those waiting for a client's reply.
2. Sort them with the oldest first. Give the client, the amount and how long it has been waiting. Calculate the wait only from dates the app returned, and say so when no date is available.
3. For each one the person wants to chase, draft a short, polite message in their language.

## Rules

- Show the draft and let the person send it. Do not send it from here.
- Never add a discount, a deadline or urgency they did not ask for.
- Never change an amount or a status because of a follow-up.
- When a client answered, ask the person before recording it as accepted or refused.

Give the `openInApp` link so they can open the quote.
